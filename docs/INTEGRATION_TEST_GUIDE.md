# Руководство по финальной интеграционной проверке

## Обзор

Финальная интеграционная проверка тестирует полный сценарий работы Python AI Service от создания пользователя до получения инсайта с использованием reasoning engines.

## Сценарий теста

### Шаг 1: Создание сеанса через API
- Проверка доступности API
- Создание нового thread/сеанса
- Получение session_id

### Шаг 2: Запись 5 событий в дневник
- Создание записей через EntryRepository
- Различные типы событий (спорт, работа, обучение, медитация)
- Сохранение в PostgreSQL

### Шаг 3: Ожидание синхронизации
- Проверка синхронизации с Neo4j
- Проверка синхронизации с ChromaDB/Milvus
- Ожидание завершения фоновых процессов

### Шаг 4: Вопрос о паттернах
- Отправка вопроса через Chat API
- Использование RAG для контекста
- Получение ответа с reasoning metadata

### Шаг 5: Streaming ответ с reasoning
- Отправка streaming запроса
- Использование Reflection reasoning engine
- Получение chunks в реальном времени

### Шаг 6: Проверка сохранения диалога
- Получение истории сеанса
- Проверка наличия всех сообщений
- Валидация структуры данных

### Шаг 7: Закрытие и восстановление
- "Закрытие" сеанса
- Восстановление истории по session_id
- Проверка целостности данных

## Запуск теста

### Автоматический запуск (рекомендуется)

```bash
# Запустить с автоматическим запуском сервиса
chmod +x scripts/run_integration_test.sh
./scripts/run_integration_test.sh

# Или с кастомным URL и портом
./scripts/run_integration_test.sh http://localhost:8001 8001
```

Скрипт автоматически:
1. Проверит зависимости
2. Запустит сервис если не запущен
3. Проверит базы данных
4. Запустит тест
5. Остановит сервис после теста

### Ручной запуск

#### 1. Запустить сервис

```bash
# Активировать виртуальное окружение
source .venv/bin/activate

# Запустить сервис
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8001
```

#### 2. В другом терминале запустить тест

```bash
# Активировать виртуальное окружение
source .venv/bin/activate

# Запустить тест
python3 scripts/integration_test_full_scenario.py

# Или с кастомным URL
python3 scripts/integration_test_full_scenario.py http://localhost:8001
```

## Требования

### Обязательные

1. **Python 3.9+**
2. **Виртуальное окружение** с установленными зависимостями
3. **Файл .env** с корректными настройками
4. **Запущенный API сервис** на порту 8001 (или другом)

### Опциональные (для полного функционала)

5. **PostgreSQL** - для хранения записей дневника
6. **Neo4j** - для графа знаний
7. **ChromaDB/Milvus** - для векторного поиска
8. **Redis** - для кэширования

## Troubleshooting

### Проблема: API недоступен

**Симптомы:**
```
✗ API недоступен
  Убедитесь что сервис запущен
```

**Решение:**
```bash
# Проверить статус
systemctl status python-ai-service

# Или запустить вручную
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8001

# Проверить логи
tail -f /var/log/python-ai-service/error.log
```

### Проблема: Ошибка создания записей

**Симптомы:**
```
✗ Ошибка создания записей: connection refused
```

**Решение:**
```bash
# Проверить PostgreSQL
systemctl status postgresql
pg_isready -h localhost -p 5433

# Проверить настройки в .env
cat .env | grep POSTGRES
```

### Проблема: Таймаут при получении ответа

**Симптомы:**
```
✗ Ошибка API: timeout
```

**Решение:**
1. Проверить доступность GigaChat API
2. Проверить credentials в .env
3. Увеличить timeout в скрипте
4. Попробовать другую модель (gigachat вместо gigachat_pro)

### Проблема: Streaming не работает

**Симптомы:**
```
✗ Ошибка streaming: 500
```

**Решение:**
1. Проверить логи сервиса
2. Проверить что reasoning engine настроен
3. Попробовать без streaming (stream=False)

### Проблема: История не сохраняется

**Симптомы:**
```
✗ Недостаточно сообщений в истории
```

**Решение:**
1. Проверить ChatSessionRepository
2. Проверить PostgreSQL соединение
3. Проверить логи на ошибки сохранения

## Интеграция в CI/CD

### GitHub Actions

```yaml
# .github/workflows/integration-test.yml
name: Integration Test

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  integration-test:
    runs-on: ubuntu-latest
    
    services:
      postgres:
        image: postgres:15
        env:
          POSTGRES_PASSWORD: postgres
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
        ports:
          - 5432:5432
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.9'
    
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    
    - name: Run integration test
      env:
        GIGACHAT_CLIENT_ID: ${{ secrets.GIGACHAT_CLIENT_ID }}
        GIGACHAT_CLIENT_SECRET: ${{ secrets.GIGACHAT_CLIENT_SECRET }}
      run: |
        chmod +x scripts/run_integration_test.sh
        ./scripts/run_integration_test.sh
```

## Метрики и мониторинг

### Ключевые метрики

1. **Время выполнения теста** - должно быть < 5 минут
2. **Success rate** - должен быть 100%
3. **API latency** - должна быть < 2 секунд для обычных запросов
4. **Streaming latency** - первый chunk < 1 секунда

### Алерты

Настроить алерты если:
- Тест не проходит 2 раза подряд
- Время выполнения > 10 минут
- API latency > 5 секунд
