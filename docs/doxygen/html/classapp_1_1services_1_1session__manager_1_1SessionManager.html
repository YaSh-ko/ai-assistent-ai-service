Detailed Description

@brief Менеджер чат-сессий.

Управляет жизненным циклом сессий:
- Создание и получение сессий (PostgreSQL + in-memory кеш).
- Сохранение сообщений в историю.
- Хранение checkpoint-состояний для LangGraph SDK.
- Валидация и закрытие сессий.

Кеш инвалидируется при сохранении нового сообщения.
