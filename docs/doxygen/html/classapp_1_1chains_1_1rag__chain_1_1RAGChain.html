Detailed Description

@brief Основной RAG-пайплайн Delёz на базе LangGraph.

Граф состоит из узлов:
- classify_query → retrieve_events → filter_relevant
- filter_relevant → (simple) generate_response | (complex) cot_reasoning
- cot_reasoning → generate_response → save_to_db → END

Зависимости инжектируются через конструктор, что упрощает тестирование.

@brief Собирает полный промпт для LLM.

Структура промпта:
1. История диалога (последние 5 сообщений).
2. RAG-контекст из записей дневника.
3. Шаги CoT-рассуждения (до 5 шагов, только для COMPLEX).
4. Текущий вопрос пользователя.

@param question        Текущий вопрос.
@param context         Текстовый контекст из RAG.
@param reasoning_steps Шаги CoT-рассуждения.
@param history         История диалога (опционально).
@return Готовый промпт в виде строки.
