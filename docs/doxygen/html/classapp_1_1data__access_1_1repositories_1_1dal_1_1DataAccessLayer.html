Detailed Description

@brief Слой доступа к данным (Data Access Layer).

Агрегирует репозитории:
- session_repo       — сессии пользователей.
- chat_session_repo  — история чат-сессий.
- entry_repo         — записи дневника (PostgreSQL).
- entry_thread_repo  — связи записей с диалогами.
- goal_thread_repo   — связи целей с диалогами.
- experiment_thread_repo — связи экспериментов с диалогами.
- analysis_thread_repo   — связи анализов с диалогами.
- embedding_repo     — векторные эмбеддинги (ChromaDB).

Создаётся через DatabaseFactory.create_dal_async().

@brief Атомарно сохраняет запись дневника и её эмбеддинг.

Шаги:
1. Создаёт запись в PostgreSQL через entry_repo.
2. Сохраняет эмбеддинг в ChromaDB (если не передан — использует нулевой вектор).
3. Привязывает запись к диалогу через entry_thread_repo (если thread_id задан).

@param user_id     ID пользователя-владельца.
@param title       Заголовок записи.
@param description Текст записи.
@param event_date  Дата события.
@param thread_id   ID диалога для привязки (опционально).
@param embedding   Вектор эмбеддинга (опционально, 1024-мерный).
@return Объект записи с атрибутом id (SimpleNamespace).
@throws RuntimeError Если запись не удалось создать в PostgreSQL.
