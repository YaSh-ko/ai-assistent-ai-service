@brief Выполняет семантический поиск по запросу.

Генерирует эмбеддинг запроса с инструкцией для улучшения качества поиска
и возвращает топ-k похожих документов.

@param query  Текст поискового запроса.
@param k      Количество возвращаемых результатов (по умолчанию из конфига).
@param filter Фильтр метаданных для ChromaDB (опционально).
@return Список словарей с полями page_content, metadata и score.
