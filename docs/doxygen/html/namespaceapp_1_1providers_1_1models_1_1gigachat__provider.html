Detailed Description

@file gigachat_provider.py
@brief Универсальный провайдер для GigaChat API (Base / Pro / Max).

Реализует IModelProvider с поддержкой:
- OAuth2-аутентификации через Sberbank OAuth endpoint.
- Синхронной генерации (generate) и стриминга токенов (stream).
- Автоматического обновления access token за 60 секунд до истечения.
- Метрик через ModelMetrics (Prometheus).
- SSL через сертификаты Минцифры (get_gigachat_ssl_context).

Версии модели задаются через параметр version: "base", "pro", "max".
