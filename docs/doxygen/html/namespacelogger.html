Detailed Description

@file logger.py
@brief Настройка логирования и специализированный ModelLogger.

Инициализирует root logger при импорте модуля.
Предоставляет get_logger() с кешированием через lru_cache
и ModelLogger для структурированного логирования операций с LLM.
