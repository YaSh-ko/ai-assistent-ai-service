Detailed Description

@brief Абстрактный интерфейс для LLM-провайдеров.

Все провайдеры (GigaChatProvider, VLLMProvider) реализуют этот интерфейс,
что позволяет ModelFactory и LLMService работать с любым провайдером
без изменения кода.
