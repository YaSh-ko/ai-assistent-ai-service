Detailed Description

@brief Менеджер стриминговых ответов.

Форматирует поток токенов от LLM в SSE-события для кастомного Chat API.
Отличается от LangGraph-совместимого формата (event: values) —
использует data: {"type": "...", "data": {...}}.

@brief Генератор SSE-событий для стриминга ответа LLM.

Последовательность событий:
1. processing — старт обработки.
2. reasoning_step — шаги CoT (если переданы).
3. text — токены ответа LLM.
4. done + [DONE] — завершение стрима.
5. error — при исключении.

@param session_id      ID сессии.
@param llm_stream      Async generator от LLM-провайдера.
@param reasoning_steps Список шагов CoT-рассуждения (опционально).
@yields Строки SSE-событий.
