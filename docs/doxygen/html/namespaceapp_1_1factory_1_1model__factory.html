Detailed Description

@file model_factory.py
@brief Фабрика LLM-провайдеров с кешированием и fallback-логикой.

Управляет жизненным циклом провайдеров GigaChat и vLLM:
- Создаёт провайдеры по имени и кеширует их (thread-safe через Lock).
- Поддерживает автоматический fallback при недоступности модели.
- Предоставляет методы для проверки доступности и закрытия сессий.
