Detailed Description

@brief Сервис анонимизации персональных данных.

Обрабатывает строки и вложенные структуры данных (dict, list),
заменяя найденные PII на плейсхолдеры.

Поддерживаемые типы PII:
- Email-адреса → [EMAIL]
- Телефонные номера (международный формат) → [PHONE]
