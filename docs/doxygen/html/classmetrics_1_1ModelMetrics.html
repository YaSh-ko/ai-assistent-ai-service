Detailed Description

@brief In-memory метрики LLM-моделей (Singleton, thread-safe).

Агрегирует latency, tokens, success rate по каждой модели.
Дополнительно экспортирует данные в формате Prometheus через
to_prometheus_format() (используется эндпоинтом /models/metrics/prometheus).
