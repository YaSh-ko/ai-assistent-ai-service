Detailed Description

@brief Сервис управления движками рассуждения.

Выбирает CoT или Reflection в зависимости от типа задачи,
выполняет рассуждение и хранит историю результатов в памяти.

@note В production историю следует хранить в Redis или PostgreSQL.

@brief Выполняет процесс рассуждения.

Выбирает движок, вызывает engine.reason() и сохраняет результат в историю.
При ошибке возвращает структуру с полем "error" вместо исключения.

@param question   Вопрос пользователя.
@param context    Контекст (результаты RAG-поиска, user_id, thread_id).
@param task_type  Тип задачи для выбора движка.
@param user_id    ID пользователя (для логирования и истории).
@return Словарь с ключами: answer, steps, metadata, reasoning_id.
