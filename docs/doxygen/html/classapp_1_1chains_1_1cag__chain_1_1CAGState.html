Detailed Description

@brief Состояние CAG-пайплайна, передаваемое между узлами LangGraph.

Поля:
- question, user_id, thread_id, session_id — входные данные.
- search_results    — результаты поиска.
- relevance_grades  — оценки релевантности каждого документа.
- filtered_results  — документы с оценкой RELEVANT или PARTIALLY_RELEVANT.
- needs_correction  — флаг необходимости коррекции.
- draft_answer      — черновик ответа.
- answer            — финальный ответ.
- correction_attempts — счётчик попыток коррекции.
- correction_feedback — список проблем, найденных при проверке качества.
- selected_model, processing_time_ms — метаданные.
