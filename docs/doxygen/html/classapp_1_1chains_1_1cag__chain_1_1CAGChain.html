Detailed Description

@brief Corrective Augmented Generation Chain.

Добавляет слой проверки качества поверх RAG:
1. Оценка релевантности найденных документов по score-порогу.
2. Генерация черновика ответа через LLMService.auto_select_and_generate().
3. Проверка качества: длина, маркеры неуверенности.
4. Коррекция при необходимости (до max_correction_attempts раз).
5. Финализация.

@brief Шаг 2: оценка релевантности каждого документа.

Использует эвристику по score:
- score ≥ threshold → RELEVANT
- score ≥ threshold * 0.7 → PARTIALLY_RELEVANT
- иначе → NOT_RELEVANT

Оставляет только RELEVANT и PARTIALLY_RELEVANT документы (топ-5).

@param state Текущее состояние пайплайна.
@return Обновлённое состояние с relevance_grades и filtered_results.
