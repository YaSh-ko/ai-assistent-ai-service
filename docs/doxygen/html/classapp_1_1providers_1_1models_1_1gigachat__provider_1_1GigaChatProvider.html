Detailed Description

@brief Провайдер для GigaChat API.

Поддерживает все три версии модели: Base, Pro, Max.
Управляет OAuth-токеном, HTTP-сессией и метриками.

Использование:
@code
provider = GigaChatProvider(version="pro")
response = await provider.generate("Привет!")
@endcode

@brief Получает или обновляет OAuth access token.

Токен кешируется и обновляется за 60 секунд до истечения.
Поддерживает два способа аутентификации:
- Base64-encoded credentials (GIGACHAT_CREDENTIALS).
- client_id + client_secret (формирует Basic auth header).

@return Действующий access token.
@throws ModelError Если credentials не заданы.
@throws ModelUnavailableError При ошибке HTTP или неверном статусе ответа.
