Detailed Description

@brief Сервис разбивки текста на смысловые чанки.

Использует RecursiveCharacterTextSplitter с приоритетными разделителями:
"\\nUser:", "\\nAI:", "\\n\\n", "\\n", " ", "".
Это позволяет сохранять границы реплик при разбивке чат-истории.
