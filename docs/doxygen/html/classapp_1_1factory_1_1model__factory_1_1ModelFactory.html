Detailed Description

@brief Фабрика для создания и управления LLM-провайдерами.

Реализует паттерн Singleton для каждого провайдера:
при повторном запросе возвращает закешированный экземпляр.

Порядок fallback при недоступности модели:
gigachat → gigachat_pro → gigachat_max → vllm.
