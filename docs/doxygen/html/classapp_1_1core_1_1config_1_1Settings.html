Detailed Description

@brief Главный класс настроек приложения.

Все поля читаются из переменных окружения или .env-файла.
Pydantic автоматически валидирует типы и применяет model_validator'ы.

Группы настроек:
- Общие (APP_NAME, DEBUG, LOG_LEVEL)
- Модели (CURRENT_MODEL, маппинги сложности → модель)
- Конфигурации GigaChat Base / Pro / Max и vLLM
- Поиск (гибридный BM25 + vector, reranker)
- Эмбеддинги и чанкинг
- Базы данных (PostgreSQL, Neo4j, Redis, ChromaDB, Milvus)
- CoT и Reflection
- Credentials (GIGACHAT_CREDENTIALS, VLLM_API_KEY)
