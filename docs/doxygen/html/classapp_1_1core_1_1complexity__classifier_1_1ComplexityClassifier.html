Detailed Description

@brief Классификатор сложности запросов пользователя.

Анализирует текст запроса и возвращает ComplexityResult с уровнем
сложности и рекомендуемой моделью.

Критерии классификации:
- SIMPLE:  короткие вопросы, FAQ, приветствия, простые команды.
- MEDIUM:  анализ записей, начало дневника, исследование эмоций.
- COMPLEX: поиск паттернов, глубокий анализ, сравнение периодов.

Используется как синглтон через get_complexity_classifier().

◆ classify()

ComplexityResult app.core.complexity_classifier.ComplexityClassifier.classify ( self,
str query,
Optional[QueryContext] context = None ) 
@brief Классифицирует запрос по уровню сложности.

Алгоритм:
1. Проверяет простые паттерны (приветствия, FAQ) — если нет MEDIUM/COMPLEX слов.
2. Считает COMPLEX-ключевые слова; если ≥2 или длина ≥300 → COMPLEX.
3. Проверяет MEDIUM-ключевые слова.
4. Fallback по длине строки.

@param query   Текст запроса пользователя.
@param context Дополнительный контекст (thread_id, user_id) — опционально.
@return ComplexityResult с уровнем, уверенностью и рекомендуемой моделью.
