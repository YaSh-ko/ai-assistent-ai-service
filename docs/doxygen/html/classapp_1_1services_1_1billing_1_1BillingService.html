Detailed Description

@brief Сервис расчёта стоимости токенов GigaChat.

Singleton — создаётся один раз и переиспользуется через billing_service.
Определяет тариф по имени модели (prefix-matching) и записывает
метрики в Prometheus при каждом вызове record().

@brief Возвращает тариф для указанной модели.

Использует prefix-matching: "GigaChat-Pro" → PRICING["GigaChat-Pro"].
При неизвестной модели возвращает тариф "default" (GigaChat Base).

@param model Имя модели (например, "GigaChat-Pro").
@return Словарь с ключами "input" и "output" (руб / 1000 токенов).
