Detailed Description

@file deps.py
@brief FastAPI Dependency Injection — синглтоны сервисов и цепочек.

Все зависимости создаются лениво (при первом запросе) с thread-safe
asyncio.Lock. Используются через Depends() в эндпоинтах.

Синглтоны:
- LLMService, ReasoningService, PIIService — stateless сервисы.
- DataAccessLayer — инициализирует все PostgreSQL-репозитории.
- SessionManager — менеджер чат-сессий с in-memory кешем.
- RAGChain — полный пайплайн с BM25+Vector+Graph поиском.

DataAccessLayer app.api.deps.get_dal_async ( ) 
@brief DI-зависимость: возвращает singleton DataAccessLayer.

При первом вызове подключается к PostgreSQL и инициализирует
все репозитории. При ошибке подключения бросает HTTP 503.

@return Инициализированный DataAccessLayer.
@throws HTTPException 503 если PostgreSQL недоступен.

◆ get_rag_chain()

RAGChain app.api.deps.get_rag_chain ( ) 
@brief DI-зависимость: возвращает singleton RAGChain с полной интеграцией.

При первом вызове инициализирует:
- DataAccessLayer (PostgreSQL + ChromaDB).
- BM25Provider + VectorSearchProvider → HybridSearchProvider.
- GraphRepository (Neo4j, опционально — деградирует gracefully).
- EmbeddingService, LLMService, ReasoningService, RerankerProvider, PIIService.

@return Полностью инициализированный RAGChain.
