Detailed Description

@brief Выбирает подходящую LLM-модель и параметры генерации.

Маппинг сложности → модель:
- simple  → gigachat      (GigaChat Base)
- medium  → gigachat_pro  (GigaChat Pro)
- complex → gigachat_max  (GigaChat Max)

Параметры генерации (temperature, top_p, max_tokens) также
зависят от уровня сложности.

Union[str, Any] app.core.model_selector.ModelSelector.select_model ( str query_or_complexity,
bool prefer_privacy = False,
bool prefer_speed = False )
static 
@brief Выбирает модель по уровню сложности или тексту запроса.

Если передан уровень сложности ("simple" / "medium" / "complex") —
возвращает строку с именем модели.
Если передан произвольный текст — классифицирует его и возвращает
провайдер (для обратной совместимости с тестами).

@param query_or_complexity Уровень сложности или текст запроса.
@param prefer_privacy      Если True — принудительно использует vLLM (локальная модель).
@param prefer_speed        Зарезервировано, пока не используется.
@return Имя модели (str) или экземпляр IModelProvider.
