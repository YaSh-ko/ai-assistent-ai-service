Detailed Description

@brief Фабрика для создания экземпляров баз данных.

Использует паттерн Singleton с thread-safe double-checked locking.
Все методы статические — экземпляр фабрики не создаётся.

Поддерживаемые БД:
- PostgreSQL 15 (реляционная)
- Neo4j 5 (графовая, ризома)
- ChromaDB (векторная)
- Milvus (альтернативная векторная)

@brief Создаёт или возвращает singleton-экземпляр Neo4jProvider.

Выполняет health check при создании нового экземпляра.
При неудаче health check — закрывает провайдер и бросает RuntimeError.

@param provider_type Тип провайдера (только "neo4j").
@param force_new     Если True — создаёт новый экземпляр, игнорируя кеш.
@return Экземпляр IGraphDatabase.
@throws RuntimeError Если Neo4j недоступен.
@throws ValueError   Если передан неизвестный тип провайдера.
