Detailed Description

@file metrics.py
@brief Prometheus-метрики и in-memory статистика AI-сервиса.

Prometheus-счётчики/гистограммы экспортируются на /metrics.
ModelMetrics и ReasoningMetrics — thread-safe singleton'ы
для in-memory агрегации статистики (latency, tokens, success rate).
