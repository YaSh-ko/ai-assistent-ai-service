Detailed Description

@file complexity_classifier.py
@brief Классификатор сложности пользовательских запросов.

Определяет уровень сложности запроса (SIMPLE / MEDIUM / COMPLEX),
чтобы направить его к подходящей модели GigaChat:
- SIMPLE  → GigaChat Base (быстро, дёшево)
- MEDIUM  → GigaChat Pro  (анализ, дневник)
- COMPLEX → GigaChat Max  (паттерны, глубокий анализ)

Классификация основана на:
- Регулярных выражениях для приветствий и FAQ.
- Ключевых словах средней и высокой сложности.
- Длине запроса как fallback-критерии.
