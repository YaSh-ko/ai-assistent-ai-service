Detailed Description

@file main.py
@brief Точка входа AI-сервиса Delёz.

Здесь поднимается FastAPI-приложение, регистрируются все роутеры,
подключается Prometheus-метрики и настраивается CORS.
При старте прогревается ReasoningService и проверяется доступность моделей GigaChat.

@author Команда Delёz
@version 0.1.0

◆ create_app()

FastAPI app.main.create_app ( ) 
@brief Создаёт и конфигурирует экземпляр FastAPI.

Регистрирует:
- CORS-middleware с разрешёнными origins (prod + localhost).
- Все API-роутеры под префиксом /api/v1.
- Prometheus-метрики на /metrics.
- HTTP-middleware для сбора метрик по каждому запросу.
- Глобальный обработчик исключений с CORS-заголовками в ответе.
- Эндпоинты /health, /info и редирект / → /docs.

@return Сконфигурированный экземпляр FastAPI.

◆ lifespan()

app.main.lifespan ( FastAPI app) 
@brief Управляет жизненным циклом приложения (startup / shutdown).

При старте:
- Прогревает ReasoningService, чтобы первый запрос не тормозил.
- Проверяет доступность всех моделей GigaChat и логирует результат.

При остановке:
- Закрывает соединения с базами данных (PostgreSQL, Neo4j).
- Закрывает HTTP-сессии провайдеров моделей.

@param app Экземпляр FastAPI-приложения.

app.main.setup_paths ( ) 
@brief Добавляет корневую директорию проекта в sys.path.

Нужно, чтобы Python мог найти общие модули (common/), которые
лежат выше текущего пакета. Ищет родительскую папку, содержащую
директорию 'common', и добавляет её в начало пути.

@return Путь к корню проекта или None, если не найден.
