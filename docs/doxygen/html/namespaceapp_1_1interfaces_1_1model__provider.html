Detailed Description

@file model_provider.py
@brief Интерфейс и базовые классы для LLM-провайдеров.

Определяет единый контракт для всех моделей (vLLM, GigaChat и др.):
- IModelProvider — абстрактный интерфейс.
- BaseModelProvider — базовая реализация с общей функциональностью.
- ModelConfig, ModelResponse, StreamChunk — структуры данных.
- ModelError и подклассы — иерархия исключений.
