Delёz AI Service — документация

Что это такое

Delёz AI Service — Python-микросервис, реализующий интеллект персонального ассистента Delёz. Сервис принимает запросы от API-сервиса, выполняет RAG-пайплайн на базе LangGraph и возвращает ответы через SSE-стриминг.

Название и концепция вдохновлены философией ризомы Жиля Делёза: вместо линейного дневника пользователь получает живой граф, где события, эмоции и выводы связаны между собой.

Production-домен: https://delez.tech

Архитектура

Сервис построен по Clean Architecture с явным разделением слоёв:

Слой Путь Назначение
API app/api/ FastAPI-эндпоинты, SSE-стриминг
Сервисы app/services/ Бизнес-логика (LLM, Embedding, Search, Reasoning)
Цепочки app/chains/ LangGraph-пайплайны (RAG, CAG)

Мониторинг app/monitoring/ Prometheus-метрики, логирование

RAG-пайплайн (5 шагов)

Основной пайплайн обработки запросов реализован в RAGChain (app/chains/rag_chain.py):

Шаг Узел Описание
0 classify_query Определение сложности (SIMPLE/MEDIUM/COMPLEX)
1 retrieve_events Гибридный поиск BM25 + Vector + Graph → топ-10
2 filter_relevant Reranker → топ-5 релевантных записей
3 cot_reasoning Chain-of-Thought (только для COMPLEX)
4 generate_response Генерация ответа GigaChat
5 save_to_db Сохранение в PostgreSQL + Neo4j + ChromaDB

Выбор модели по сложности

Сложность Модель Когда

Поисковая система

Запрос пользователя
↓
HybridSearchProvider (BM25 + Vector) → топ-10
↓
RerankerProvider (GigaChat) → топ-5
↓
Контекст для LLM
  • BM25Provider — полнотекстовый поиск по ключевым словам (PostgreSQL).
  • VectorSearchProvider — семантический поиск по эмбеддингам (ChromaDB).
  • HybridSearchProvider — комбинация BM25 + Vector с нормализацией скоров.
  • RerankerProvider — финальное ранжирование через GigaChat API.

Ключевые возможности

  • RAG-пайплайн на LangGraph с 5 шагами обработки.
  • Адаптивный выбор модели GigaChat по сложности запроса.
  • Гибридный поиск BM25 + Vector + Graph (Neo4j).
  • Chain-of-Thought и Reflection reasoning для сложных запросов.
  • SSE-стриминг, совместимый с LangGraph SDK и agent-chat-ui.
  • PII-анонимизация перед сохранением данных.
  • Prometheus-метрики: latency, tokens, cost, active requests.
  • Zero-Knowledge Architecture: сервер не хранит расшифрованные данные.
  • CI/CD через GitLab, контейнеризация Docker.
